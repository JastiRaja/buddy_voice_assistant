# 📜 J.A.R.V.I.S. Voice Commands Guide

Welcome to the comprehensive voice command reference for **J.A.R.V.I.S. (v5.0)**. You can speak any of these commands naturally after saying the wake word (*"Hey Jarvis"*, *"Jarvis"*, or *"Buddy"*), or while in continuous hands-free session mode.

---

## 📁 1. Files & Folder Management

| Spoken Command | What It Does |
| :--- | :--- |
| **"Open folder [name]"** | Opens any library or subfolder (e.g. *"Open folder camera roll"*, *"Open folder screenshots"*) |
| **"How many folders are in [name] folder?"** | Counts and names all subfolders in the requested directory |
| **"How many files are in [name] folder?"** | Counts and previews files (e.g. *"How many files are in pictures folder?"*) |
| **"How many items in [name] folder?"** | Reports total count breakdown of folders and files |
| **"Open [library]"** | Opens standard folders (*"Open pictures"*, *"Open downloads"*, *"Open documents"*, *"Open desktop"*) |
| **"List files" / "Show files"** | Lists recent files in the current or specified folder |
| **"Open latest file" / "Open latest download"** | Finds and launches the most recently modified/downloaded file |
| **"Clean up downloads" / "Organize folder"** | Automatically categorizes files into Images, Docs, Code, Installers, etc. |
| **"Open [letter] drive"** | Opens any mounted drive volume (e.g. *"Open C drive"*, *"Open D drive"*) |
| **"Open This PC" / "Open My Computer"** | Opens File Explorer drives and devices overview |

## 🚀 4. Apps & Window Management

| Spoken Command | What It Does |

| **"Close [app name]" / "Close window"** | Safely closes focused window or specific running application |
